# The Legend of Zelda: Link's Awakening — Recompiled Online

### An Unofficial Multiplayer Extension of LAS Recomp

**Project Maintainer:** ThyHeroOfTime  
**Project:** LAS Recomp Online  
**Current Release:** V15.2  
**Status:** Community-Driven Development

## About This Project

LAS Recomp Online is a community-driven multiplayer project built upon the work of the original Link's Awakening Recompiled developers.

The goal of this project is to expand the original PC recompilation experience by introducing online multiplayer functionality, cooperative gameplay, player-hosted sessions, and additional quality-of-life improvements while preserving the foundation established by the original development team.

This project represents countless hours of development, testing, troubleshooting, debugging, and refinement. What began as an effort to bring players together in Link's Awakening has grown into an ongoing technical undertaking involving networking infrastructure, gameplay synchronization, compatibility, user interface development, and multiplayer stability.

As the project maintainer, I oversee its direction, feature requirements, integration, testing, bug investigation, and release preparation. Development involves continuous experimentation, reviewing results, identifying problems, and refining implementations until they meet the project's intended functionality.

This is an independently maintained community extension and should not be confused with the original LAS Recomp project.

## Multiplayer Development Goals

LAS Recomp Online focuses on making cooperative gameplay accessible without requiring players to understand complicated networking configurations.

The project's development priorities include:

- Player-hosted online multiplayer sessions
- Public and private multiplayer lobbies
- Private lobby codes and session discovery
- Multiplayer gameplay synchronization
- Player identification and customization
- Local cooperative gameplay compatibility
- Controller support and accessibility
- Network reliability and connection recovery
- Continued compatibility with upstream LAS Recomp improvements
- Integrated bug reporting and community feedback

The long-term objective is to provide a straightforward multiplayer experience where players can host or join sessions with minimal setup.

Features and availability may vary between releases, and functionality under active development should not be considered complete until it has been tested.
